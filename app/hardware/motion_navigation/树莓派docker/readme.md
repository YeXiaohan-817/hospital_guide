# 🚗 CYBER-BOT VLA 项目：树莓派端（边缘执行与局部导航）实现指南

本文件专门介绍 **CYBER-BOT 具身智能车载控制项目** 中**树莓派端（边缘端）**的代码实现、核心节点分工、传感器驱动以及启动指令。

在整个端边云协同架构中，树莓派端专注于**高实时性硬件采集、底层安全防护、局部避障与运动执行**。

---

## 一、 树莓派端核心定位与职责

树莓派 4B 作为小车的“小脑与身体”，主要承担以下四大核心任务：

1. **传感器数据采集**：通过 USB 接口实时驱动摄像头采集图像，通过串口驱动 LD19 激光雷达采集环境点云。
2. **底层安全感知与规避**：运行 APF（人工势场法）局部导航与障碍物规避节点，结合雷达数据实现毫秒级反应的盲区刹车与安全倒车。
3. **底盘运动学执行**：接收高层指令（`/cmd_vel`），通过 `gpiozero` 硬件引脚精确控制四个麦克纳姆轮的 PWM 调速与转向。
4. **实时状态发布**：向 ROS 2 网络发布压缩图像、雷达扫描数据和里程计信息。

## 三、 核心代码实现详解

### 1. 麦克纳姆轮底盘驱动 (`mecanum_driver.py`)
底盘驱动负责将高层的速度指令（`Twist`）转化为四个电机的底层硬件 PWM 控制，并处理机器人坐标系的里程计（Odometry）和静态坐标变换。

* **核心功能**：
  * **硬件引脚控制**：使用 `gpiozero` 的 `PWMOutputDevice` 和 `OutputDevice` 控制电机驱动板。
  * **运动学逆解**：支持线速度与角速度的矢量叠加合成运动。
  * **死区过滤与限幅**：过滤微小漂移，设置最小起步 PWM（0.15）和最大上限（0.80），保护硬件。
  * **里程计与 TF 广播**：发布 `/odom` 话题及 `base_link` 到 `camera_link` 的静态 TF 变换。

### 2. APF 局部导航与障碍物避障节点 (`apf_navigator_node.py`)
这是树莓派端最具技术挑战的局部导航控制核心。它在没有全域地图的情况下，实时让小车在“寻找目标”与“避开障碍”之间做权衡。

* **核心功能**：
  * **紧急倒车与解困**：当激光雷达检测到前方极近距离（小于 0.21 米）出现障碍物时，立即触发紧急倒车，打破盲目驻停。
  * **卡死检测与突围**：引入“直行打滑卡死”与“原地旋转受阻”的双重检测机制。若倒车后方受阻，自动切换为“向前突围逃逸”模式。
  * **动态避障与视觉融合**：结合 YOLO 传来的目标方向（`/yolo_target_vector`）与雷达（`/scan`）数据，中途遇到垃圾桶等中间障碍时自动触发动态绕行。
  * **精确驻停与盲进校验**：支持大目标与小目标（垂直盲区）的精准到达判定，并增加偏航防错校验，防止歪头面对非目标物误判停车。

## 四、 树莓派端传感器与节点启动指令合集

在树莓派容器或终端中，各模块的推荐启动顺序与完整命令如下：

### 1. 启动 LD19 激光雷达驱动
雷达通过 USB 转串口连接，启动前确保赋予串口权限：

```bash
sudo chmod 777 /dev/ttyUSB0
cd ~/ros2_ws
source install/setup.bash
ros2 launch ldlidar_stl_ros2 ld19.launch.py
```
