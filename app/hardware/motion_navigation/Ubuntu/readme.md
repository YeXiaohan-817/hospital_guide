# ⚡ CYBER-BOT VLA 虚拟机/PC 端实现说明

本文档专门介绍 **CYBER-BOT 具身智能车载控制中枢** 项目中运行在 **Ubuntu 虚拟机 / PC 端** 的核心代码与功能实现。虚拟机端充当整个系统的**“高层认知大脑”与“视觉感知中枢”**，负责自然语言交互、多模态大模型（VLM）推理决策以及 YOLOv8 视觉目标跟踪。

---

## 一、 虚拟机端核心定位与职责

在端边协同架构中，树莓派 4B 作为物理底盘负责底层传感器采集与硬件控制，而 **Ubuntu 虚拟机/PC 端** 则承载高算力和高层智能逻辑：
1. **自然语言与语义交互**：接收用户的自然语言指令，通过视觉大模型理解场景并转化为具身导航目标。
2. **多模态视觉大模型驱动 (FastAPI + VLM)**：结合摄像头实时图像流与大模型（如 Gemini 2.5 Flash），进行高层语义解析与目标类别映射。
3. **高帧率视觉目标定位 (YOLOv8)**：基于轻量化 YOLOv8 算法，对摄像头图像进行实时目标检测，计算目标的相对偏航角与距离，驱动底盘进行精准对准与追踪。

---

## 二、 核心代码文件架构与功能详解

虚拟机端主要包含三个核心组件：`index.html`（赛博朋克交互控制台）、`main.py`（FastAPI 服务与 VLM 大脑网关）和 `yolo_detector_node.py`（YOLOv8 视觉跟踪与空间定位节点）。

### 1. `index.html` —— 赛博朋克风格控制台与人机交互前端
位于项目前端的 Web 界面，提供沉浸式的赛博朋克风格交互体验。
* **主要功能**：
  * **实时聊天与状态显示**：用户可以通过自然语言与 CYBER-BOT 交互，界面实时展示系统连接状态和当前锁定的物理目标 (`LOCKED: ...`)。
  * **流式交互与动态加载**：内置“VLM 思考中”的动态点阵动画，提供良好的交互反馈。
  * **智能中断机制**：设计了动态交互按钮（发送箭头 ↔ 中断正方形），支持用户随时通过 `AbortController` 中断正在进行的 AI 推理与指令下发。

### 2. `main.py` —— FastAPI 后端服务与 ROS 2 桥接大脑
作为高层决策中枢，结合了 FastAPI 异步 Web 服务与 ROS 2 节点线程。
* **核心实现**：
  * **ROS 2 后台桥接 (`FastAPIRosBridge`)**：订阅树莓派发布的压缩图像话题 `/image_raw/compressed` 并缓存在内存中 (`latest_frame_base64`)；同时负责将大模型解析出的高层目标发布到 `/high_level_target` 话题。
  * **多模态大模型 API 集成**：集成 OpenAI 兼容客户端，调用高性能视觉大模型（如 `[满血A]gemini-2.5-flash`）。
  * **意图识别与 COCO 映射**：将用户的自然语言请求与当前摄像头的 Base64 图像打包发送给大模型，要求其判断用户意图，若为寻物导航则从 COCO 80 常用物体类别池中挑选最匹配的目标英文单词（如 `chair`, `bottle`, `person` 等），并以纯 JSON 格式返回。

### 3. `yolo_detector_node.py` —— YOLOv8 视觉目标跟踪与空间几何计算
作为“小脑”级视觉执行节点，运行在 ROS 2 环境中，实现高帧率的目标检测与跟踪。
* **核心实现**：
  * **话题订阅与发布**：订阅 `/image_raw/compressed` 图像流与 `/high_level_target` 高层目标指令；发布目标视觉矢量 (`/yolo_target_vector`) 供后续 APF 导航或底盘控制使用。
  * **空间几何防抖与 TTL 记忆**：引入帧间缓存与生存时间 (TTL) 机制，避免因单帧漏检导致目标丢失；通过空间距离匹配筛选最佳候选目标。
  * **偏航角与距离换算**：根据目标在画面中的像素中心位置与相机水平视场角 (FOV)，计算相对偏航角 `error_x`（左正右负，直接指导底盘转向），并根据边界框高度估算相对距离，实现“目标对准与安全刹停”双重逻辑。
  * **GUI 实时可视化**：提供 OpenCV 可视化窗口实时渲染检测框、置信度、中心对齐辅助线以及锁定状态。

## 三、 虚拟机端数据流与闭环逻辑

```text
用户在网页端 (index.html) 输入自然语言
                 │
                 ▼
       FastAPI 服务端 (main.py)
                 │
                 ├─────► 结合树莓派实时图像 (/image_raw/compressed)
                 │
                 ▼
        VLM 大模型 (Gemini-2.5) 语义推理
                 │
                 ▼
       发布高层语义目标 (/high_level_target)
                 │
                 ▼
     YOLOv8 视觉定位节点 (yolo_detector_node.py)
                 │
                 ▼
     计算相对矢量并输出 (/yolo_target_vector)
```

1. **指令输入**：用户在 `index.html` 输入“我想找地方坐”。
2. **大模型决策**：`main.py` 抓取当前摄像头画面，调用大模型解析出目标为 `chair`，并通过 ROS 2 广播 `/high_level_target: chair`。
3. **视觉追踪**：`yolo_detector_node.py` 接收到目标类别后，利用 YOLOv8 在实时画面中锁定椅子，计算其偏航偏差，输出空间控制矢量。

## 四、 快速运行与部署指南

### 1. 环境依赖安装
在 Ubuntu 虚拟机环境中，确保安装了所需的 Python 库：
```bash
pip install fastapi uvicorn openai opencv-python ultralytics cv_bridge pydantic
```

### 2. 启动 FastAPI 高层大脑服务
```bash
python3 main.py
```
*(注：请确保已正确配置 ROS 2 环境变量及中转站 API Key)*

### 3. 启动 YOLOv8 视觉物理执行节点
在另 一个 ROS 2 终端中启动：
```bash
python3 yolo_detector_node.py
```
搭配树莓派端的相机推流与底盘驱动，即可实现完整的“自然语言驱动—视觉语义理解—目标精确定位”的具身智能闭环！
